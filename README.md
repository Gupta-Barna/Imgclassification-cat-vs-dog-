# Imgclassification-cat-vs-dog
A deep learning based project for classifying images as Cat or Dog using Python, TensorFlow, Keras, and MobileNetV2.
# Project Overview
The goal of this project is to build an image classification model that can look at an image and determine whether it contains a Cat or a Dog.
The trained model can also take a new uploaded image and predict its class.
# The project uses a Cat/Dog dataset, without putting all 25,000 images into the repository.

# Technologies
-Python
-TensorFlow / Keras
-MobileNetV2
-NumPy
-Matplotlib
-Google Colab

# Steps
-Image dataset preparation
-Image preprocessing
-MobileNetV2 transfer learning
-Cat/Dog classification
-Model training
-Model evaluation
-Upload a new image and get a Cat/Dog prediction
